# Anime-Recommendation-System

Developed an Anime Recommendation System using Python and Streamlit, implementing a Content-Based Filtering approach to recommend anime based on user preferences.

The system utilizes TF-IDF Vectorization to extract and represent anime genre and type features, then applies Cosine Similarity to measure the similarity between user preferences and available anime titles. The recommendation score combines genre similarity (70%) and anime type similarity (30%).

Users can customize their recommendations by selecting preferred genres, anime types, minimum ratings, and minimum member counts, with adjustable recommendation results (Top-N).
